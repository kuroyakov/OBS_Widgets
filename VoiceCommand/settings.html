音声コマンド設定

音声認識字幕ちゃん連動の OBS 音声コマンド設定を voice_command_config.json へ保存します（サーバー再起動は不要）。

API トークンが必要です

LAN 経由で設定を操作する場合は、サーバーの twitch_config.json に記載された api_token を入力してください。

1. 全体設定

ウェイクワード・クールダウン・音量調整のステップ幅を設定します。

〜

2. 音量・ミュート対象マッピング

対象エイリアス（カンマ区切り）に対し、「上げて / 下げて / ミュート / ミュート解除」が自動展開されます。

3. カスタムコマンド

OBS フィルタ切替・OBS ホットキー実行・離席中モード切替を割り当てます。

4. テスト発話・実行履歴

設定保存後に発話テキストを入力してコマンド判定と OBS 動作を確認できます。
