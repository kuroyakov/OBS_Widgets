# `EndRoll/` — わんコメ連携エンドロール（参加者自動集計クレジット）

わんコメ (OneComme) が収集したコメント・通知をもとに、配信開始から終了までにコメント・サブスク・ギフト・ビッツ・レイドしてくれたリスナーをリアルタイムで自動集計し、`Ending` シーンに表示された際に映画風のエンドロールとして下から上へスクロール表示するウィジェットです。対象サービスはわんコメの収集対象（Twitch / ツイキャス等）で、集計は直近4時間以内のコメントが対象です。

## ファイル構成と主な責務

```text
EndRoll/
├── README.md        # 本ドキュメント
├── index.html       # OBS ブラウザソース用エンドロール画面 (~70行)
├── css/
│   └── style.css    # フォント・クレジットレイアウト・スクロール演出スタイル (~150行)
└── js/
    └── app.js       # わんコメ OneSDK 購読・ロール別リスナー集計・OBSシーン連動スクロール開始 (~430行)
```

## 動作の仕組み

* わんコメのテンプレートとして配置し、`preset/__origin/js/onesdk.js`（OneSDK）経由でコメント・通知・配信情報を受け取ります。自前サーバーや `shared/` には依存しません。
* 配信タイトルは OneSDK の `meta`（配信情報）から自動で反映します。クレジットに出す配信者名は `js/app.js` の `CONFIG.streamer` で設定します（空のままなら行ごと表示しません）。
* OBS のブラウザソース設定で「表示されていないときにソースをシャットダウンする」の**チェックを外して**常時裏で動かしておくことで、配信中のチャット参加者を漏れなく記録します。
* `Ending` シーンに切り替わってブラウザソースがアクティブ（可視状態）になったタイミングで自動的にクレジットロールがスタートします。

## セットアップ（配布パッケージ利用時）

1. わんコメ (OneComme) のテンプレートフォルダ内に、このフォルダをそのまま配置します（`preset/__origin/js/onesdk.js` を相対参照するため、配置場所が必須です）。
2. `js/app.js` の `CONFIG.streamer` に自分の配信者名を設定します（空欄の場合はクレジットに配信者名の行を表示しません）。
3. OBS のブラウザソースでこのフォルダの `index.html` を開き、「表示されていないときにソースをシャットダウンする」のチェックを外して常時動作させます（詳細は上記「動作の仕組み」を参照）。
