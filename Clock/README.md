# `Clock/` — 配信用 日付・デジタル時計ウィジェット

OBS の配信画面隅に配置する、視認性の高い日付・曜日・現在時刻（秒付き）のデジタル時計オーバーレイです。

## ファイル構成と主な責務

```text
Clock/
├── README.md        # 本ドキュメント
├── Date.html        # OBS ブラウザソース用時計HTML (~35行)
├── css/
│   └── style.css    # 文字サイズ・配色・背景カード枠・シャドウ等のスタイル定義 (~120行)
└── js/
    └── clock.js     # 現在日時・曜日のフォーマットと毎秒更新ロジック (~58行)
```

## カスタマイズ方法

* フォントサイズ、文字色、背景の透過度・角丸はすべて [css/style.css](css/style.css) 冒頭の `:root` CSS変数で簡単に調整できます。

## セットアップ（配布パッケージ利用時）

1. OBS のソースに「ブラウザ」を追加し、「ローカルファイル」にチェックして `Date.html` を指定します。
2. 以上で表示されます。追加の設定ファイルやサーバーは不要です（フォントに Google Fonts を使うため、表示にはインターネット接続が必要です）。
