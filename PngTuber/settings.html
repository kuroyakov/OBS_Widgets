PNGTuber 設定

アバターの画像・しきい値・対象マイクを pngtuber_config.json へ保存します（サーバー再起動は不要）。

API トークンが必要です

LAN 経由で設定を保存する場合は、サーバーの twitch_config.json に記載された api_token を入力してください。

対象アバター

編集するアバターを切り替えます。追加アバターは OBS のブラウザソースで index.html?avatar=名前 を指定して表示します。

1. 対象マイクソース

OBS の音声入力ソースを選択します。空（自動選択）の場合は OBS のマイク入力を自動検出します。

2. 入力レベルとしきい値

ライブメーターを見ながら、口が開く・閉じるしきい値を調整できます。

level: -∞ dB 口: 閉
-60 -40 -20 0 dBFS
close open

この値以上で口が開きます（既定: -26.0 dB）。

この値以下で口が閉じます（既定: -32.0 dB / open_threshold 以下に自動制限。下限 -60 dB はリニア 0.001 として保存）。

別マイクが発話中に、相手より指定 dB 以上小さいかぶり音を抑制します（0 で無効、複数マイク時は 6 dB 推奨）。

3. アバター画像（4枚1組）

.png ファイルをアップロードすると PngTuber/images/ に保存され即座に反映されます。images/ にある既存ファイルから選ぶこともできます。
